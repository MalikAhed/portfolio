# Portfolio world — brainstorming index

Research date: 25 August 2026

This folder is planning material only. No existing production file was edited as
part of this brainstorm.

## Scope

The proposed final journey is deliberately short:

> Hero → About → Skills → Projects → Contact

`Work` and `Journal` are not part of this direction. When implementation begins,
the navigation should eventually reflect only the real destinations.

## Recommended cut in one paragraph

Keep the current Hero and About story, then let the completed About absorption
become the entrance to **Capability Orbits**: Malik's skills emerge as a useful
build system inside the event horizon. Tilt the final orbit edge-on until it
becomes the first plane in **Proof in Depth**, a corridor of project worlds that
the camera approaches and passes through. After the last project, remove almost
all motion and arrive at **The Quiet Horizon**, where a single signal travels to
the contact action. The narrative is **identity → motivation → capability →
evidence → invitation**.

## The key creative rule

Do not install every impressive effect. One memorable spatial idea, repeated
with different meaning, will feel more authored than twelve unrelated effects.
The black hole, orbit, focus pull, and camera travel are the grammar; cards,
text effects, particles, and cursor behavior are supporting punctuation.
